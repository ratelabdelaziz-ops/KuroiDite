Python

FileFlow

A Python automation tool that cleans, organizes, and renames messy files across folders.

PythonAutomation
ProblemFiles saved with random names, dropped in the wrong folders, and duplicated everywhere. Every cleanup was a long manual slog and easy to get wrong.
BuildA script that scans folders, detects file types, renames to a consistent pattern, sorts into the right place, and skips duplicates, with checks for missing dirs and bad names so it never crashes mid-run.
ResultA cleanup that used to take a long manual session now runs in seconds, and the folders stay organized instead of going chaotic again.

LuaU

RoundCore

A custom Roblox system managing rounds, player states, rewards, and game flow.

LuaURoblox
ProblemRounds started inconsistently, players spawned in the wrong state, rewards misfired, and events could be triggered out of order. The whole loop felt unstable.
BuildA full round manager in LuaU handling joining, spawning, countdowns, transitions, and rewards. Split into small single-job systems, with server-side validation, reset logic, and anti-glitch timing.
ResultRounds run in the right order, rewards land correctly, and the loop stays solid even with late joins and early leaves. It's also easy to extend without breaking the core.
